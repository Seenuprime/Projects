# ML/DL Mini-Projects

A collection of standalone deep learning and computer vision mini-projects built while learning TensorFlow/Keras and CV fundamentals.

## Included
- American Sign Language recognition
- Hand sign detection with OpenCV
- Multi-digit recognition
- Food Vision (image classification milestone project)
- Time series forecasting with RNNs
- MNIST digit classification (CNN)
- Language identification from text

## Tech stack
Python, TensorFlow/Keras, OpenCV, Jupyter Notebook
